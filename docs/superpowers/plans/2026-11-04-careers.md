# Careers Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Careers section (`/careers`, `/careers/<slug>`, `/careers/<slug>/apply`, `/careers/apply`) built from the Figma designs, with jobs, page copy and applications fully managed in the admin.

**Architecture:** Jobs are a new versioned collection cloned from services (table, module, admin editor, public detail). The pages' copy is a new fixed page `careers` in the template registry. Applications are a new inbox cloned from leads, with an optional CV kept in private storage and served only to signed-in enquiry handlers.

**Tech Stack:** Next.js 16 (Cache Components), Hono API, Drizzle/Postgres, zod, TanStack Query, SchemaForm, Tailwind, GSAP (HomeMotion), vitest + Playwright.

**Spec:** `docs/superpowers/specs/2026-11-04-careers-design.md`

## Global Constraints

- Read `node_modules/next/dist/docs/` before writing a route (AGENTS.md).
- No user-visible literal in public components: every string comes from the `careers` page copy or job content (`tests/unit/public-literals.test.ts`; add `components/careers` to its `PUBLIC_DIRS`).
- Public reads: `"use cache"` + `cacheLife("max")` + tags `tag.jobs`, `tag.job(slug)`, `tag.page("careers")`; every write invalidates them.
- Job slug: `^[a-z0-9]+(-[a-z0-9]+)*$`, at most 120 characters, unique.
- CV: PDF, DOC or DOCX by sniffed bytes, at most 5 MB, key prefix `private/applications/YYYY/MM/<uuid>.<ext>`, never a `media` row.
- Applications endpoint: body limit 5 MB + 64 KB envelope; rate limit bucket `applications`, 5 per 10 minutes per IP.
- Retention default 12 months (`settings.careers.retentionMonths`, 1–36).
- "Open" = published, `closed_at` null, `closingDate` null or ≥ today in `Europe/Dublin`.
- Colours map to the existing tokens (brand, navy, navy-dark, line, surface, ink, body); reuse `PageHero`, `SectionHeading`, `Container`, `buttonVariants`.
- Re-baseline `tests/unit/blocks/frozen-components.json` when a frozen public component changes.

## Review Focus

1. Someone guesses a CV URL under `/api/v1/media/file/private/...` → 404 (Task 8 test `public file route never serves a CV key`).
2. A visitor submits to a job that closed after the page loaded → 409 and the "role has closed" notice, nothing stored (Task 9 test `refuses an application to a closed job`).
3. A job whose closing date is today, checked at 23:30 Irish time → still open (Task 3 test `closing date counts in Irish time`).
4. An executable renamed `cv.pdf`, or a 6 MB PDF → 422 on the `cv` field, no file kept in storage (Task 8 test `rejects a disguised or oversized CV`).
5. A tampered form posting a shift or certificate not in the published options → 422 on that field (Task 9 test `rejects options that are not in the published form`).
